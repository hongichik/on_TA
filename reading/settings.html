Link Web App (Apps Script) đã được cài sẵn trong code nên bạn không cần cấu hình gì thêm. Đây là ngân hàng "Reading Plus" — dùng chung 1 Apps Script với app Trắc nghiệm nghe, chỉ khác sheet lưu dữ liệu (ReadingBank / ReadingStats).

Lấy link này ở bước Deploy > New deployment > Web app trong Apps Script (xem hướng dẫn bên dưới).

Khởi tạo dữ liệu Reading Plus (một lần)

  1. Mở Google Sheet đang dùng cho app Trắc nghiệm nghe (cùng 1 Sheet).
  2. Vào Extensions > Apps Script, đảm bảo đã dán bản apps-script/Code.gs mới nhất (có thêm phần Reading Plus).
  3. Ở thanh công cụ, chọn hàm setupReading (khác với setup dùng cho trắc nghiệm nghe) rồi bấm Run — chạy đúng 1 lần để tạo sheet "ReadingBank" (138 câu) và "ReadingStats".
  4. Nếu đã Deploy Web app từ trước thì không cần deploy lại — cùng 1 URL phục vụ cả 2 ngân hàng câu hỏi.

Nếu chưa từng deploy Web app, làm theo hướng dẫn đầy đủ ở trang Cài đặt của app Trắc nghiệm nghe (mục "Hướng dẫn tạo kết nối"), rồi dùng chung URL đó ở đây.
