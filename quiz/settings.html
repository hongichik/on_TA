Kết nối Google Sheet

← Trang chủ

Dán link Web App (Apps Script) đã deploy từ Google Sheet của bạn vào đây. Sau khi kết nối, các trang luyện tập sẽ tự lấy câu hỏi từ Sheet (kể cả câu bạn mới thêm) và tự ghi lại câu trả lời sai vào Sheet.

Lấy link này ở bước Deploy > New deployment > Web app trong Apps Script (xem hướng dẫn bên dưới).

Hướng dẫn tạo kết nối (một lần)

  1. Mở Google Sheet bạn muốn dùng.
  2. Vào menu Extensions (Tiện ích mở rộng) > Apps Script.
  3. Xoá hết code mẫu, dán toàn bộ nội dung file apps-script/Code.gs (đi kèm trong thư mục dự án) vào.
  4. Bấm biểu tượng lưu (Ctrl/Cmd+S), đặt tên project tuỳ ý.
  5. Ở thanh công cụ, chọn hàm setup rồi bấm Run — chạy đúng 1 lần để tạo 2 sheet "Questions" và "WrongStats" và nạp sẵn 246 câu hỏi. Lần đầu Google sẽ hỏi cấp quyền: chọn tài khoản > Advanced > Go to project (unsafe) > Allow (an toàn vì đây là script của chính bạn).
  6. Vào Deploy > New deployment, chọn loại Web app. Mục "Execute as" chọn Me, mục "Who has access" chọn Anyone, rồi bấm Deploy.
  7. Copy Web app URL vừa được cấp, dán vào ô phía trên và bấm Lưu, sau đó Kiểm tra kết nối.

Lưu ý: khi chọn "Anyone", ai có link Web App này cũng có thể đọc/ghi dữ liệu — phù hợp cho mục đích cá nhân luyện tập, nhưng đừng chia sẻ link đó công khai.
